# Karo Trip

A small, plan-based travel companion for Karo's Bali trip.

The first milestone focuses on one thing: **where is Karo right now, according to the plan?**

## MVP direction

- Polish-first UI with English switch
- Bali journey map
- Karo avatar / marker
- itinerary-driven current location
- local Bali time + Warsaw reference time
- day / sunset / night visual state
- preview time control for testing

## Development

The initial implementation is intentionally dependency-light so the core journey logic can be reviewed before adding map/weather infrastructure.
