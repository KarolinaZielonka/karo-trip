# Karo Trip — Product Specification

The first implementation milestone is a small, plan-based travel companion for Karo's Bali trip.

## Current milestone

- Polish-first UI with a compact PL / EN switch
- illustrated, schematic Bali journey map
- itinerary-driven current location
- local Bali time and Warsaw reference time
- day, sunset, dawn and night visual states
- simple journey timeline
- editable preview time for testing

The product is intentionally not GPS-based. Location is derived from the travel plan.
